Бесплатная программа для игроков NOVA RP (GTA 5): оверлей-справочник с правилами проекта, чтобы не получать наказания по незнанию.

- Окно появляется только поверх игры и открывается по горячей клавише (настраивается), в углу экрана — подсказка клавиши.
- База правил собирается с форума автоматически каждые 3 часа (GitHub Actions) и разбирается в дерево: разделы, пункты, наказания, примечания, картинки. Поправки «Было / Стало» учитываются.
- Программа для Windows на Tauri 2, установка через .exe, обновления базы и программы — по окну с предложением обновить.
- Следующий этап: встроенный ИИ-помощник, который отвечает по правилам.
