# nova-helper — памятка для Claude

**Что это:** NOVA HELPER — бесплатный оверлей-справочник правил проекта NOVA RP (GTA 5) для игроков. Репозиторий: MRFUNFOX/NOVA-HELPER. Программа: Tauri 2 (`app/`), парсер правил (`parser/`), дизайн-токены (`design/tokens.css`).

**Три главных приоритета:**
1. Нормальный захват окна игры: окно и подсказка видны только в игре, не когда она свёрнута. Игра — в оконном или оконном без рамки режиме.
2. Интуитивный удобный интерфейс, программа не должна сильно нагружать компьютер.
3. Правила оформлены так, чтобы было сразу понятно, какой пункт к чему относится.

**Решено:**
- Только правила проекта, законодательную базу серверов не делаем (код для законов есть, выключен `collectLaws: false`).
- Источник — форум https://forum.nova-rp.com/forums/893/; разрешение администрации на парсинг и оверлей есть, но помогать они не будут, API не дадут.
- Парсер автономный: каждые 3 часа, проверка изменений; вручную правила не собираем.
- Дизайн: чёрная тема с жёлтыми акцентами, цвета с форума.
- Установка через .exe, всё настраивается само или мастер первого запуска ведёт за руку — пользователи обычные.
- Обновления базы и программы — окно с предложением обновить, без переустановки.

**ИИ-помощник (следующий этап):** бесплатный, быстрый, один. Формат ответа: 1) краткий вердикт со ссылкой на правило; 2) объяснение, которое можно скопировать игроку в репорт; 3) мера наказания.

**Ограничения:** только бесплатная инфраструктура, за хостинг не платим. Владелец не технарь — любые действия на его стороне описывать пошагово.
